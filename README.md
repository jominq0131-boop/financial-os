# 🚀 Financial OS · Japan Edition (v1.8.4)

> **"Financial OS는 일본에 거주하는 한국인이 자산(엔화 ￥ 기준), 현금흐름, 게이밍 재정 레벨, 신NISA, 50년 생애 주기를 100% 무료 GitHub Pages와 브라우저 로컬 보안으로 총괄 제어하는 개인 재정 관제 슈퍼 대시보드입니다."**

---

## 📌 최근 주요 개선 내역 (v1.8.4)

- 💰 **자산 금액 실수치(`￥301,000`) 전면 표기**: 30만엔 같은 축약 숫자를 제거하고 정확한 엔화 원본 실수치를 대시보드 전체에 표시
- 🎮 **게이밍 레벨 연산 공식 & 4대 퀘스트 프로그레스 바 신설**: 레벨이 왜 2인지(기본 자산 Lv + 저축률 보너스 Lv), 다음 레벨까지 얼마(￥)가 남았는지, 퀘스트별 % 달성 바 공개
- 💡 **'이번 달 저축·투자 가능 잉여금' 직관화**: 실수령 수입 - 월 지출 = 저축 가능 자금 개념 명확화
- 🛡️ **툴팁 팝업 잘림 방지 (`z-[9999]`)**: 카드 테두리나 UI 요소에 가려지지 않도록 팝업 레이어 최우선 순위 격상

---

## 🎮 주요 기능 스펙

### 🏆 게이밍 재정 랭킹 & FIRE 퀘스트 센터
- **투명한 레벨 & 경험치 (Lv. 1 ~ Lv. 99)**: 기본 자산 레벨 (200만엔당 +1) + 저축률 보너스 (20%당 +1) 공식 공개 및 다음 레벨 필요 금액(￥) 표시
- **4대 FIRE 메인 퀘스트 실시간 진척률 % 바**:
  - 🛡️ `3개월 비상금 수호자`: 3개월 필수 생활비 비상금 달성률 %
  - 📈 `신NISA 파이어니어`: 신NISA 연간 한도 50% 이상 달성률 %
  - 🚀 `8자리 자본가`: 총자산 1,000만 엔 (10M JPY) 돌파 달성률 %
  - 👑 `FIRE 쿼터 백`: FIRE 은퇴 목표 자금 25% 돌파 달성률 %

### 📊 월 지출 세부 카테고리화 & 도넛 차트
- 월 지출을 **주거비(월세/공과금), 식비(장보기/외식), 통신·고정비, 여가·취미, 투자·저축 적립**으로 분류
- 지출 카테고리별 비중을 **도넛 차트(Donut Chart)**로 시각화 분석

### 🌐 100% 무료 GitHub Pages 자동 웹 배포
- `npm run dev` 없이 스마트폰/PC 웹 브라우저에서 상시 접속 (`https://jominq0131-boop.github.io/financial-os/`)
