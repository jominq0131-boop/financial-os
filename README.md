## 📌 최근 주요 개선 내역 (v2.2.1 - 2026-08-01)

- 🧭 **FIRE 스마트 재정 진단 & 최적 가이드 센터 (`FireAdvisorCard`)**:
  - 수입 대비 소비율, 저축/투자율, 신NISA 적립률을 종합 평가하여 **재정 체력 점수(100점 만점)** 및 등급(`S~C등급`) 산출
  - **월 1만 엔 지출 절약 ➔ 투자 전환 시 은퇴 목표 달성이 몇 개월 단축되는지 실시간 자동 연산**
  - 고정 주거비(월세/공과금)와 순수 생활 변동 지출을 명확히 분리하여 현실적인 20~25% 변동지출 가이드 제시
- 🧮 **월 현금흐름 4축 배분 체계 & 자본 유입 시뮬레이션 개편**:
  - `수입(Income)`, `소비지출(Expense)`, `안전저축(Savings - 예·적금)`, `자산투자(Investment - NISA)` 4대 축 구축
  - $\text{월 실질 자본 유입액} = \text{안전저축} + \text{자산투자} + \text{순잉여금}$ 연산 엔진 탑재 (50년 자산 성장 차트 및 FIRE 목표 달성월 연동)
- ⚡ **지출 온도계 100% 자동 연동 & 이중 입력 완전 제거**:
  - `월 현금흐름 탱크` 입력값 100% 자동 연동으로 중복 입력 피로감 완전 해결
- 📦 **백업/복원 규격 최신화 (JSON Schema v2.1.0/v2.2.1)**:
  - 4축 현금흐름, 자산 포트폴리오, 스냅샷, 세제 설정 통합 내보내기/불러오기 지원
- 🔒 **글로벌 재정 상수 중앙 모듈화 (`src/constants/finance.ts`)**:
  - 신NISA 평생 한도(`1,800만 엔`) 및 세제 상수 캡슐화로 코드 품질과 유지보수성 극대화

## 🎮 주요 기능 스펙

### 🚀 100% 시각화 관제 요약 (Overview)
- **4대 핵심 KPI**: 총자산, FIRE 진척도, 월 자가배당 4% 룰, 신NISA 한도 소진율
- **FIRE 스마트 재정 진단표**: 재정 체력 점수(100점) & 1만엔 절약 시 FIRE 달성 단축 연월 실시간 가이드
- **목표 달성 페이스 예측 시뮬레이터**: 실질 자본 유입속도 기준 단기/중기/FIRE 목표 달성월 자동 연산
- **50년 장기 자산 복리 성장 차트**: 4축 자본 유입속도 연동 50년 미래 예측
- **월간 자산 스냅샷 성장이력 차트**: 총자산(합계) vs 투자자산 명확 구분 분석

### 📊 4축 현금흐름 & 자동 지출 온도계 (Assets & Cashflow)
- **4축 배분 탱크**: 수입, 소비지출, 안전저축(예·적금), 자산투자(NISA) 원스톱 관리
- **자동 지출 온도계**: 이중 입력 없이 현금흐름 데이터 기반 🔴과다/🔥주의/✅안정 지출 실시간 알림
