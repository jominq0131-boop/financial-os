## 🎮 주요 기능 스펙

### 🚀 100% 시각화 관제 요약 (Overview)
- 4대 KPI(총자산, FIRE 진척도, 월 자가배당 4% 룰, 신NISA 연간 한도)
- 목표 달성 페이스 예측 시뮬레이터 & 50년 장기 자산 성장 복리 차트
- 월간 자산 스냅샷 성장이력 차트 (전월 대비 MoM 증감 분석)

### 📊 현금흐름 & 지출 온도계
- 지출 카테고리(주거, 식비, 고정비, 여가, 교통, 기타) 비중 분석 도넛 차트
- 전월 대비 카테고리별 증감률 비교 및 지출 위험/주의/안정/절약 온도계 알림

### 🌐 100% 무료 GitHub Pages 자동 웹 배포
- `npm run dev` 없이 스마트폰/PC 웹 브라우저에서 상시 접속 (`https://jominq0131-boop.github.io/financial-os/`)
- 백엔드 서버 없이 브라우저 `localStorage`에만 데이터가 저장되어 **서버 비용 0원 + 개인정보 유출 위험 0%** 완벽 보장
