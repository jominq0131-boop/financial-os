# 🚀 Financial OS (Lifetime Personal Financial Mission Control)

> **"Financial OS는 단편적인 투자 관리 앱이 아닌, 인생 전체의 미션, 현금흐름, 리스크, 생애 주기를 총괄 통제하는 개인 재정 백본 시스템입니다."**

---

## 📌 주요 특징
- **Privacy-First & Local-First**: 서버 의존 없이 개인의 재정 데이터 완벽 소유 (JSON Vault & IndexedDB).
- **Life Financial Timeline Simulator**: 물가상승률, 투자 수익률, 생애 주기 이벤트(주택 구입, 은퇴, 안식년)에 따른 미래 자산 시뮬레이션.
- **Runway & Health Control**: 소득 중단 시 생존 가능 기간(Runway) 및 FIRE 달성률 실시간 제어.
- **3-Tier Capital Allocation**: 안전망(Safety), 성장(Growth), 미션/꿈(Mission) 버킷 관리 체계.
- **Time-Price & Value Alignment**: 내 노동 시간(Hourly Real Wage) 기준 지출 가치 평가.

---

## 🛠️ 기술 스택
- **Framework**: Next.js (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Vanilla CSS Glassmorphism
- **State & Database**: Zustand, Dexie.js (IndexedDB)
- **Visualization**: Recharts, Lucide Icons

---

## 🚀 빠른 시작

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000` 접속.
